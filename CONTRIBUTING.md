# Contributing

Thanks for stopping by.

## Adding a script

1. Pick the right folder (`01-basics/`, `02-intermediate/`, `03-advanced/`,
   or `04-projects/`).
2. Filename: lowercase, hyphens, descriptive. e.g. `parse-csv.sh`.
3. Start every script with a header block:

   ```bash
   #!/usr/bin/env bash
   # <one-line description>
   #
   # Usage: ./script.sh [args]
   # Teaches: variables, loops, etc.
